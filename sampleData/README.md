# Sample Knowledge Articles

These eight short articles are the sample HR knowledge base used while building and testing the project. Create them in a dedicated HR knowledge base and publish them.

The article text here is a short summary, written for this project. The articles in the test instance may be longer.

**Two sources of knowledge in the test instance:**
- The eight sample articles in this folder, created for the project.
- Additional articles that were loaded with the HRSD plugin's demo data, for example the tuition reimbursement policy (KB0000116) and an anti-harassment policy (KB0000103) that appear in the test results. Their text is not included here.

Retrieval is scoped to one knowledge base through the system property `sn_hr_core.hr_kb_sys_id`. Put every article you want the agent to use in that knowledge base.
